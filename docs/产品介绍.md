# 具身智能数据生产平台 · 产品介绍

> 面向具身智能（人形/机械臂/四足）**训练数据的采集、质检、标注、建集与交付**的一体化生产平台。
> 本文为高保真交互原型（`../具身智能数据生产平台-高保真交互原型.html`）的产品说明，功能与界面一一对应。

---

## 一、它解决什么问题

具身智能训练数据的三大现实困难：**采集成本高、场景/机型难覆盖、采完不知道"质量到底有没有变好"**。

平台的设计出发点不是"多做一个看板"，而是把**数据是否合格**这个判断**尽量前移**：能在采集时拦掉的，绝不放到质检；能在质检拦掉的，绝不放到标注后。越靠前拦截，纠正成本越低——这是全站反复出现的同一句话。

---

## 二、核心功能

### 三端分工（同一份数据的三副面孔）

| 端 | 面向谁 | 主要做什么 |
| --- | --- | --- |
| **平台端**（桌面 Web） | 项目经理 / 质检员 / 数据工程师 | 8 个域、30 个页面：生产、质量、标注、数据集、仿真、看板、安全、配置 |
| **采集端**（移动优先） | 现场采集员 | 当日任务卡、SOP 作业页（实时五项质量指标 + 质量灯 + 异常打点 + 分段重采）、上传队列、弱网离线 |
| **客户门户**（外部只读） | 客户 / 验收方 | 项目概览、交付与验收、数据集下载、**结构化异议**（异议锚定到具体帧与字段） |

### 平台端 8 个功能域

- **生产**：总览看板 · 任务列表 · 批次 · 上传与校验中心 · 语义检索与取数
- **质量**：待办队列 · 质检台 · 规则配置台
- **标注**：标注任务与排产 · 标注工作台 · 标注质检与逐帧批注
- **数据集**：配方库 · 配方编辑器 · 快照与版本 · 导出与交付 · 开放接口
- **仿真**：仿真接入 · 合成数据生成 · 虚实融合配比
- **看板**：产能 / 进度 / 质量 / 成本四类视图
- **安全**：加密与密钥 · 生命周期与销毁 · 水印与溯源
- **配置**：规格模板 · 本体与设备台账 · 接入契约 · 点位与人员 · 权限与角色 · 审计日志

### 五条贯穿全站的主线

1. **数据飞轮 · 模型在环**——采集 → 质检 → 预标注 → 建集 → 训练引用 → 难例回流，末环回指首环。模型不只是被交付的产物，也是生产环节里的协作者（机审证据链、主动学习难例队列、配方模型建议）。
2. **质量前置**——上传即校验，三态结论（通过 / 有条件通过 / 不通过），每条不通过都能一跳定位到具体帧或字段；校验服务自身故障标记为"待补校验"而非"不通过"，不误伤数据。
3. **提问式取数**——「找数据」从翻目录变成提问：用自然语言描述"要哪一批"（场景 / 技能 / 结果 / 质量分 / 时长），系统解析为结构化条件后**真实过滤语料**并给出命中数；条件可见、可点掉、可在左侧筛选面板勾选微调；命中为空时给出空态与一键出路。解析与筛选共用同一套条件词表，不会出现"说了 A 筛出 B"。
4. **交付不是终点**——交付物四件一体（数据集 + Data Card + 质量报告 + 验收单）；客户算法团队持续取数走**开放接口**，而非一次性压缩包。
5. **契约即资产**——设备按契约接入，不合契约的消息在入库前被拒绝。

## 三、设计原理

1. **判断前移 > 事后补救**。校验分两级：先过**契约级校验**（消息类型 / 时间域 / 必填字段 / 边界值），再走常规流水线（解封装、时间对齐、Schema、去重、抽帧、脱敏、一致性）。不合契约的消息在这最便宜的一步就被挡住。

2. **硬件与软件解耦**。任何能按契约发布标准消息（ROS2 topic）的设备都能接入；换机型、换场景、换点位，只改**两层 YAML 配置**，核心采集服务一行代码不动。第一层会话配置回答"录什么"，第二层全局配置回答"用哪个适配器"。

3. **时间是跨流对齐的唯一前提**。所有时间戳取**数据的创建时刻**（曝光/读回/解算/收报），而非消息发布时刻；无 header 的消息一律拒绝。时钟不同步不会报错，只会让对齐**静默错位**——这是最难事后发现的一类缺陷，所以录制前强制完成时钟同步（局域网 chrony 毫秒级 / 需要更紧用 PTP 微秒级）。

4. **异常必须有出路**。每个结论都可点击下钻到证据；每个驳回都带原因码；每个异议都锚定到帧与字段。界面不留"死胡同"。

5. **克制、可长期使用的工业控制台观感**。深色石墨底 + 中性冷蓝交互色 + 语义状态色；密排、锐角小圆角、细描边、等宽数字；**无渐变文字、无毛玻璃、无发光、无装饰动效**；动效仅 150–400ms 状态反馈。背景用工程蓝图网格（32px 坐标纸）而非装饰性径向渐变。

6. **一线可用性约束**。全站可点区域满足移动端 44px（采集端放大 1.5 倍）；质检台可**全程键盘完成一轮判定**（1–5 打分、M 打证据、R 驳回、A 通过、空格播放、←/→ 逐帧），条件不满足时拦住并说明缺什么。

## 四、能力对标：向 AIRSPEED 补齐的缺口

参考开源项目 **AIRS Airspeed**（`github.com/airs-cuhk/airspeed`，具身智能数据生产平台）做能力对标，补上了此前缺失的**设备接入契约**这一环：

| 缺口 | 补齐落点 |
| --- | --- |
| 硬件-软件解耦、设备零改码接入 | 新增**「接入契约」页**：3 个接口契约（遥操作 / 机器人 / 传感器）、7 条流声明（话题 / 消息类型 / 时间域 / QoS / 字段抽取 / 速率 / 合规判定） |
| 两层 YAML 配置 | 契约页内置**会话配置 / 全局配置**可切换的 YAML 查看器，说明"换硬件 = 换适配器 + 改会话 YAML" |
| 时间域与时钟同步前提 | 契约页新增**时间域与时钟同步**面板（chrony / PTP / 远端头显未同步），与采集端"时间未同步则阻塞录制"呼应 |
| 入库时边界校验（拒绝 NaN/Inf） | 上传与校验中心新增**契约级校验**面板（4 条：header+时间域 / 必填字段 / 边界值 / 跨流对齐 ≤1 帧） |
| 落盘后多格式转换 | 导出与交付页新增**格式与转换**页签：AIRS HDF5 → Parquet / Zarr / LeRobot v3 / JSON Lines，含转换工具与推送 HuggingFace Hub |
| 设备台账缺时钟视角 | 本体与设备台账新增**时钟同步列**，并可一键跳到接入契约页 |

同时修复了**顶栏搜索栏无法输入**的问题：原先只是一个按钮 + 静态文本（没有 input 元素），现改为真实输入框，支持键入、回车检索并把查询带入检索页，另加 ⌘K / Ctrl+K 聚焦。
