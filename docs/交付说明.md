## 二、能力增强

### 模型在环 · 数据飞轮

- 总览看板加「数据飞轮 · 模型在环」六环节闭环链路（采集 → 质检 → 预标注 → 建集 → 训练引用 → 难例回流，末环回指首环）+ 四个能力指标
- 质检台加「机审证据链」：模型版本 / 拟判原因码 / 置信度 / 可跳转证据 / 历史准确率 / 采纳建议
- 标注工作台加「主动学习 · 难例回流」队列（按模型不确定度排序，而非提交时间）
- 配方编辑器加「模型建议条件」与「长尾缺口转补采」
- 上传与校验标注引擎与规则集版本

### 设备接入契约

对标开源项目 **AIRS Airspeed**（https://github.com/airs-cuhk/airspeed）的四项核心能力（硬件-软件解耦、ROS2 主题契约、入库时边界校验、落盘后多格式转换）逐项补齐：

- **新增「配置 → 接入契约」页**：3 个接口契约卡 + 7 条流声明表（话题 / 消息类型 / 时间域 / QoS / 字段抽取 / 速率 / 合规）+ 会话 / 全局两层 YAML 可切换查看器 + 时间域与时钟同步面板 + 契约拦截记录表
- **本体与设备台账新增「时钟同步」列**，并提供「查看接入契约」入口
- **上传与校验中心新增「契约级校验」面板**（header + 时间域 / 必填字段 / 边界值 NaN·Inf / 跨流对齐 ≤1 帧 四条），顶部加「接入契约已绑定」标签，流水线来源补「契约 CONTRACT-v1」
- **导出与交付页新增「格式与转换」页签**（AIRS HDF5 → Parquet / Zarr / LeRobot v3 / JSON Lines，含转换工具与推送到 HuggingFace Hub）

核心设计原则：**判断前移 > 事后补救**——不合契约的消息在入库前就被拒绝，而不是走完采集、上传、质检、标注再回溯（成本相差一个数量级）。

### 提问式取数（检索与取数）

「找数据」从翻目录变成提问：用自然语言描述要哪一批（场景 / 技能 / 结果 / 质量分 / 时长），系统解析为结构化条件后**真实过滤语料**并给出命中数。

- 语料 **37 条**，覆盖平台全部 **9 类场景 / 技能**：厨房台面折叠衣物、厨房冰箱取物、商用厨房吧台咖啡机、仓储分拣线、产线装配工位螺丝锁付、实验台电控柜线缆插拔、实验台软体布料、户外阶梯碎石四足越障、桌面多物体抓取
- `SEARCH_FACETS` **单一词表**（展示名 + 条件键 + 取值 + 同义词）驱动三处：自然语言解析、左侧筛选面板、条件标签——三处同源，不会出现「说了 A 筛出 B」
- 链路：`parseSearch()` 解析自然语言 → `mergeConds()` 合并手工条件 → `filterHits()` 过滤 → 按质量分排序
- 交互口径 **解析优先、手工接管**：未触碰的条件组由查询解析控制；一旦在面板勾选或点掉标签，该组即由手工条件接管（避免「点了取消又被解析弹回来」）；重新输入查询则回到纯解析态
- **时长单位统一为秒**：自然语言可写 秒 / 分钟（1 分钟 = 60 秒，显式换算），面板以分钟输入、标签按分钟展示；合计时长按命中真实时长求和
- 条件标签**可点击移除**，左侧筛选面板**真正可勾选**；命中为空时给出**空态**与「查看全部数据 / 放宽质量分下限 / 去掉时长区间」三个一键出路

### 顶栏搜索栏

真实 `<form>` + 受控 `<input>`：支持键入、回车检索（`onSubmit` 路由到检索页并带 `payload.q`）、⌘K / Ctrl+K 聚焦；检索页承接查询并显示「来自顶栏检索 · 问题已带入」标签。

容器宽度用 `flex: 0 1 clamp(176px, 21vw, 340px)` + `min-width: 0`，文字块单独 `overflow:hidden / text-overflow:ellipsis / white-space:nowrap`，≤1180px 再收窄，避免长占位文案把顶栏顶出视口。

### 看板下钻

总览看板**每一块都可下钻**，跳转后目标页承接上下文：

- 指标卡（在产任务 → 任务列表 / 今日上传量 → 上传与校验 / 一次通过率 → 质检台 / 待办质检 → 待办队列）
- 数据飞轮 6 个环节节点（采集 → 总览、质检 → 质检台、预标注 → 标注工作台、建集 → 配方库、训练引用 → 导出与交付、难例回流 → 标注任务）
- 风险列表「去处理」（按风险类型分别落到规则配置 / 上传与校验 / 设备台账 / 质检台 / 任务详情）
- 驳回原因分布每一行（带原因码进质检台）、热力图每个单元格（带采集员 + 场景进质检台，目标页采集员筛选被预置）、异常与边界清单每一行（带异常编号进上传与校验）

跳转统一走同一处 `go()`，并回一条 toast 说明「已带入什么上下文」。

### 新建功能

把此前只有外观、没有行为的「新建」全部接通：

- **规则配置 → 新建规则**：弹窗含编号唯一性 / 判定逻辑非空 / 阈值必须是数字三类校验，提交后写入规则表并选中新行，说明新规则以「试运行」接入
- **标注任务 → 拆包新建**：弹窗收范围、拆包方式、单元数、规范版本、首位标注员，提交后生成单元并追加到列表
- **配置域 → 新建**：按当前页列定义动态生成表单，必填校验后追加记录；审计日志页没有「新建」语义，改为「导出日志」
- **标注工作台 → 新建轨道**：在时间线追加一条可编辑轨道

### 数据交付闭环（开放接口）

**数据集 → 开放接口 · Open API** 页，五个分区：

- 接口清单（8 个端点，含方法 / 路径 / 鉴权 / 限流 / 权限点）
- 鉴权与密钥（API Key + HMAC-SHA256 签名 + 时效令牌 + IP 白名单，凭证表含生产 / 沙箱、权限点、最近调用、启停）
- 事件回调（5 类 Webhook 事件 + 幂等与退避建议）
- 调用日志（含 403 停用 / 429 限流 / 404 时效过期三类典型故障高亮）
- 接入示例（curl / Python / JS 三种语言可切换，含换令牌 → 检索 → 断点续传取媒体三步）

与既有页面联动：导出与交付页新增「通过开放接口拉取」入口；凭证与「安全 · 加密与密钥」共用 KMS 与 90 天轮换策略。设计立意：**交付不是终点**——一次性压缩包适合验收，算法团队持续取数应走接口。

### 演示数据规范

全站 107 处人名统一替换为职称：项目经理 / 数据工程师 / 质检员 / 采集员 A–C / 现场督导 / 设备工程师 / 标注员 A–D / 客户经理。替换脚本对复合词排序（「采集员 · 林敬」排在裸名之前），避免二次替换；替换后 29 页逐页扫描残留 0。客户公司名（恒立机器人等虚构代号）保留，与人员姓名不是一回事。

## 设计基调

深色工业数据控制台：石墨底 + 中性冷蓝交互色 + 语义状态色。

- 密排、锐角小圆角、细描边、等宽数字，**无渐变、无毛玻璃、无发光、无装饰动效**
- 背景用工程蓝图网格（32px 坐标纸）替代装饰性径向渐变
- 动效仅 150–400ms 状态反馈
- 全站可点区域满足移动端 44px，采集端放大到 1.5 倍
- 表格 / 时间轴 / 播放器均带真实交互，不是静态截图
- 断点体系：≤1440 密排收窄 → ≤1180 多栏转单列堆叠 → ≤900 导航转抽屉 → ≤820 顶栏精简 → ≤600 手机端（去设备外壳、触控放大）
- 能力类指标（模型侧口径）与业务指标同行距、同描边，靠信息结构区分，不靠视觉特效

## 质量验证记录

## 已修复的缺陷

1. `Timeline` 组件在未传 `folded` 时崩溃，并因 React 18 未捕获错误导致**整站白屏** → 补默认值 + 加根级错误边界（单页异常不再拖垮全站）
2. 采集端作业页动作条引用了不存在的 `onAnomaly / onStart / onStop` → 改为正确的局部处理函数
3. 检索页选择篮是页面局部 state，顶栏计数不联动，与「跨页累积」的设计承诺不符 → 提升为应用级状态
4. 上传与校验「结论」列渲染的是上传进度字段，出现**红色标签写着「已完成」** → 改为真实结论（通过 / 有条件通过 / 不通过 / 待裁决 / 待补校验 / 旁路通道）
5. 质检台键盘在条件不满足时静默无响应，违背「异常必须有出路」原则 → 补拦住原因提示
6. 图标库里已删除 `sparkle` 图标，但 3 处引用没删干净 → 实际渲染成**空 svg**（隐形占位）→ 全部替换为 `cpu` 芯片图标，并加自动化「空图标扫描」断言（全站 0 个）
7. 装饰性径向渐变的背景不符合视觉基调 → 换成工程蓝图网格
8. 窄屏下顶栏右侧按钮被 `overflow:hidden` 裁掉导致**点不到** → ≤820px 收起次要入口、≤600px 文字标签转图标
9. 质检台 4 路播放器在窄屏因 flex 收缩**塌成 128px 高** → 容器改 `flex: 0 0 auto`，375px 下恢复 785px
10. 元数据标签与面板两处内容不一致（一处改了、另一处没改）→ 加 DOM 断言复核，确保读写一致
11. 三级文字 `--text-3` 在两种主题下与面板底色的 WCAG 对比度只有 **3.5:1**（小字 AA 要求 ≥ 4.5:1）→ 深色 `#667081 → #79828f`（≈4.6:1）、浅色 `#7f8895 → #6a7280`（≈4.7:1）。保留四级文字层级（正文 14+ / 二级 5.8+ / 三级 4.6+ / 四级为禁用级），新增元素的说明文字改挂二级（5.8–7.0:1）
12. 总览看板的指标卡、飞轮节点、风险项、原因分布、热力图、异常清单此前**只弹提示、不跳转**，看板「每块都要能回答我现在要做什么」的承诺落空 → 全部改为真实路由跳转，并在目标页承接上下文（热力图带采集员筛选、原因分布带原因码）
13. 顶栏搜索的占位文案过长而容器没有收缩下限，**把顶栏顶出视口** → 文案缩短 + 容器 `clamp` 宽度 + `min-width: 0` + 文字块省略号；≤1180px 再收窄
14. 全站人名以真实姓名呈现 → 统一替换为职称，共 107 处；替换脚本对复合词排序，避免「采集员 · 林敬」被二次替换
15. 规则配置「新建规则」、标注任务「拆包新建」、配置域「新建」、标注工作台「新建轨道」**只有按钮外观、没有行为** → 逐个接通弹窗 / 表单 / 校验 / 写回列表 / toast；审计日志页没有「新建」语义，改为「导出日志」
16. 平台此前**完全没有 API / 开放接口能力**，与「数据交付闭环」的实际形态脱节 → 新增「开放接口」页，并在导出与交付页补入口、与安全域密钥管理对齐口径
17. 顶栏搜索栏**完全无法输入**——它不是输入框，只是一个 `<button>` 包了静态 `<span>`，没有任何 `<input>` 元素 → 改为真实 `<form>` + 受控 `<input>`（键入 / 回车检索 / ⌘K 聚焦 / 查询带入检索页）
18. 平台缺少**设备接入契约**这一环，与真实具身数据生产「换硬件不改代码」的形态脱节 → 对标 AIRSPEED 新增「接入契约」页 + 设备台账时钟同步列 + 上传契约级校验面板 + 交付格式与转换页签
19. 测试脚本断言仍指向已删除的 `.gsearch-text`，导致 `getComputedStyle(null)` 崩溃 → 改为检测真实 `<input>`；同时因新增「接入契约」子项，修正配置域子导航索引偏移（审计日志 4 → 5）
20. 检索页**结果与查询内容无关**：`hits = D.SEARCH_HITS` 写死 8 条（全是厨房叠衣服），「已解析为结构化条件」标签也硬编码 → 改为查询真实驱动（解析 → 过滤 → 排序），标签由解析结果生成
21. **检索语料支撑不足**：语料只覆盖 1 类场景 / 1 类技能，其它业务方向（仓储分拣、产线锁付、电控柜插拔、四足越障…）搜不到任何数据 → 扩到 37 条、覆盖 9 类场景 / 技能
22. **条件存在两套口径**：左侧筛选面板选项与自然语言解析互不相干 → 抽出 `SEARCH_FACETS` 单一词表，三处同源
23. **时长单位不一致**：语料是「分:秒」，查询与面板按「秒」，导致「5–8 秒」把 300 秒级数据全部滤掉（0 命中）→ 内部统一为秒、自然语言兼容 秒 / 分钟、面板按分钟输入；合计时长改为按真实时长求和
24. **无命中时页面空白**、条件标签点了没反应、筛选面板勾选不生效 → 补空态与一键出路、标签可移除、面板可勾选
25. 检索测试脚本中遗留一行无效语法 → 清理
